# Dashboard

<img width="1198" height="675" alt="Screenshot_20251201_145127" src="https://github.com/user-attachments/assets/49ce07f0-77ad-41c9-9bec-647a88528571" />

It is an application that has user registration and login. Simulates a pharmacy system where employees, customers, products, suppliers, categories, 
purchases and sales can be managed. It has options to list all sales and purchases and by creating each of these transactions you can print these 
movements. It has two different user roles, administrator and staff, the first can perform any task, the second has some options blocked, 
for example making purchases.

## languages used

- java
- swing
- sqlite

## tools used

- **[icons8](https://icons8.com/)**
- **[dbbrowser](https://sqlitebrowser.org/)**
